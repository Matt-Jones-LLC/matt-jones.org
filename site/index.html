How it's built

No plugin required. Flash needed a plugin. Everything I publish runs on what your browser already ships with.

  • Pages: HTML, CSS, JavaScript, written by hand. No framework and no build step.
  • Games: Canvas and Web Audio. Scores and saves stay in your own browser.
  • Toons: Written by me, generated with Runway, and played as MP4 by the browser's own video element.
  • Hosting: Static files, no servers to run. Flash Is Dead is served from Amazon S3 through CloudFront. The arcade and this page are served from GitHub Pages.
  • Diagnostics: Datadog, opt-in. Monitoring stays off until you turn it on. No session replay.
  • Checks: pytest, Ruff and Node cover links, content rules and monitoring behavior before a release.
